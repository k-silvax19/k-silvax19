## 👨‍💻 Sobre mim

Sou desenvolvedor **Full Stack**, especializado no ecossistema **C#/.NET**, com experiência prática na construção de APIs REST, aplicações web e integração com bancos de dados relacionais.

Desenvolvo soluções utilizando **ASP.NET Core, Angular, TypeScript e Entity Framework Core**, aplicando arquitetura em camadas, separação de responsabilidades, testes automatizados e boas práticas de desenvolvimento.

Também trabalho com autenticação JWT, processamento assíncrono, mensageria com RabbitMQ, integração de serviços, CI/CD e deploy em nuvem com Microsoft Azure.

**Principais áreas de atuação:**

- Desenvolvimento de APIs REST com ASP.NET Core
- Aplicações web com Angular e ASP.NET MVC
- Persistência de dados com Entity Framework Core
- Arquitetura em camadas e padrões CQRS
- Autenticação e autorização com JWT
- Mensageria com RabbitMQ e MassTransit
- Testes automatizados e validação de regras de negócio
- Deploy em nuvem e pipelines de CI/CD

## 💼 Projetos em Destaque

### 🛵 DeliveryApp — REST API

API de gerenciamento de delivery com módulos de clientes, estabelecimentos, cardápios e pedidos.

Implementa autenticação baseada em tokens, autorização por perfil, separação entre Commands e Queries, validação de regras de negócio e testes automatizados.

**Stack:** C#, ASP.NET Core, EF Core, PostgreSQL, MediatR, FluentResults, JWT e Swagger.

[![Repository](https://img.shields.io/badge/Ver_Repositório-181717?style=for-the-badge&logo=github)](https://github.com/k-silvax19/DeliveryApp)

### 📜 Gerador de Certificados — API

API para geração automatizada de certificados digitais, utilizando processamento assíncrono e mensageria.

Permite solicitar certificados de múltiplos alunos, gerar documentos PDF e disponibilizar arquivos ZIP para download.

**Stack:** .NET 10, ASP.NET Core, PostgreSQL, EF Core, RabbitMQ, MassTransit, MediatR, QuestPDF e MSTest.

[![Repository](https://img.shields.io/badge/Ver_Repositório-181717?style=for-the-badge&logo=github)](https://github.com/PingDev-51/Gerador-de-Certificados-API)

### 📧 D-Mail — Email Scheduling System

Aplicação web para criação, agendamento e gerenciamento de mensagens de e-mail.

Utiliza processamento em segundo plano para executar envios programados, persistência de dados e proteção das credenciais SMTP.

**Stack:** C#, ASP.NET Core MVC, Entity Framework Core, SQLite, SMTP/TLS e Data Protection.

[![Repository](https://img.shields.io/badge/Ver_Repositório-181717?style=for-the-badge&logo=github)](https://github.com/k-silvax19/D-Mail-Web)

### 📚 Escola de Cursos — Management System

Sistema web para administração de cursos, instrutores, alunos, turmas e matrículas.

Possui validações de domínio, gerenciamento de entidades e integração com banco de dados relacional.

**Stack:** C#, ASP.NET MVC, Entity Framework Core, SQL Server, Bootstrap e Azure.

[![Repository](https://img.shields.io/badge/Ver_Repositório-181717?style=for-the-badge&logo=github)](https://github.com/PingDev-51/Escola-De-Cursos-Web)
